# Large, Herrera, Velasco (2015) — Neural networks for beat perception in musical rhythm

**Reference:** Frontiers in Systems Neuroscience 9:159
**DOI:** 10.3389/fnsys.2015.00159

---

## Why this matters for factory-dame

Most up-to-date statement of the canonical equation as a *coupled
network* (not the single-oscillator simplification of Kim & Large
2015). Validates the **sensory→motor coupled-GrFNN architecture** —
two reciprocally-coupled GrFNNs, one perceiving the stimulus, one
generating the motor pulse. Provides the experimental "missing
pulse" evidence that the model produces beats *not present in the
stimulus envelope*. Phase 2 (rhythm bank → tempo) and the
predictive-beat motor layer trace directly to this paper.

## Canonical network equation (Eq. 2)

```
τ_i ż_i = z_i (α + i·2π + (β₁ + iδ₁)|z_i|² + ε(β₂ + iδ₂)|z_i|⁴/(1 - ε|z_i|²))
        + Σ_{j≠i} c_ij · P(ε, z_j) · A(ε, z̄_i)
        + b_i · s(t)
```

with:
- `τ_i = 1/f_i` per-oscillator time scale
- `α + i·2π` — bifurcation parameter + natural rotation (after τ-scaling)
- `c_ij` complex internal coupling weights
- `b_i` external input weight
- `s(t)` stimulus

This is the **fully coupled network form** — the formulation we should
target for Phase 1.x refactor.

## Resonant-input transformations (Eqs. 3, 4)

```
P(ε, z) = z + √ε·z² + ε·z³ + … = z / (1 - √ε·z)        (passive: drive)
A(ε, z̄) = 1 + √ε·z̄ + ε·z̄² + … = 1 / (1 - √ε·z̄)       (active: receptor)
```

`P` expands the source signal into all its harmonics; `A` is the
oscillator's receptor expansion. Their product `P(ε, z_j)·A(ε, z̄_i)`
gives the **multi-frequency resonant coupling** that lets oscillator
`i` lock to oscillator `j` at any small-integer ratio.

External input enters the same way: in our config `b_i · s(t)` is a
*linear* input. Per the canonical form, we should be using
`P(ε, s)·A(ε, z̄_i)` for the external drive too. (Phase 1.x refactor.)

## Sensory–motor coupled architecture (Fig. 4C)

Two GrFNNs:
- **Sensory layer** — receives `s(t)`, β₁ < 0, α subcritical or critical
  ("oscillations decay in the absence of input")
- **Motor layer** — α slightly *supercritical* ("spontaneous
  oscillations even in absence of input"), reciprocally connected to
  sensory layer

Reciprocal connections allow the motor layer to *predict* the next
beat by extrapolating from sensory state. This is the substrate for
predictive beat tracking and the "tap to the music" experimental
validation.

**This is Phase 3's two-layer architecture.** Sensory ≈ subcritical
DLC; motor ≈ supercritical Hopf.

## Mode-locking demonstrated (Fig. 4B)

Numerical simulations show stable phase-locking at integer ratios:

| Ratio | Stability |
|---|---|
| 1:1 | Strongest (primary resonance) |
| 2:1 | Stable (octave) |
| 1:2 | Stable (subharmonic, "missing fundamental") |
| 3:2 | Stable (perfect fifth in pitch terms) |
| 2:3 | Stable |

Higher-order ratios (5:4, 7:6, …) get progressively narrower
Arnold-tongue-style locking regions.

## Missing-pulse experimental validation

The paper's central contribution beyond the canonical model is the
**missing-pulse experiment**: human participants tap the beat to
rhythms in which the *physical* energy is concentrated at non-beat
positions (e.g. on the off-beats), but the perceived pulse is at
positions that contain *no* acoustic energy.

The GrFNN model reproduces this — the network produces a strong
oscillation at the missing-pulse frequency, generated by mode-locking
to the stimulus-present harmonics. Direct analogue to the phantom
fundamental in the pitch domain.

## Bifurcation regime per layer

Sensory layer: α near 0, β₁ < 0 — the **critical** regime (Kim & Large
2015's Critical Hopf). Phase-locks to incoming stimulus regardless of
its frequency or amplitude.

Motor layer: α > 0 — the **supercritical** regime. Spontaneous
oscillation that gets entrained by sensory→motor coupling. Provides
the *prediction* (when no stimulus is currently present, motor still
oscillates and forecasts the next beat).

## Notes for our implementation

1. **Phase 2 motor layer**: our existing motor-layer code in
   `test_two_layer_pulse.py` corresponds to this architecture. Worth
   reviewing parameters against the paper's Fig. 4 specifics.
2. **Internal coupling**: this paper makes explicit that the canonical
   equation should *include* `Σ c_ij P(ε, z_j) A(ε, z̄_i)` as part of
   the standard form. Our Phase 1.1 kernel implementation matches the
   form but is currently disabled at low amplitudes.
3. **External input transformation**: paper's Eq. 2 uses `b_i · s(t)`
   linearly for the external drive — note that this is a SIMPLIFICATION
   from Large 2010's full nonlinear input form. Both papers are
   consistent with `b_i · P(ε, s) · A(ε, z̄_i)` being the most general
   statement; weak external input is well-approximated by `b_i · s(t)`.
4. **Critical-α tuning**: for the rhythm-bank layer, target α ≈ 0
   (critical) and β₁ < 0. For the motor layer, α slightly > 0
   (supercritical Hopf). This is exactly the Phase 3 layered plan.
