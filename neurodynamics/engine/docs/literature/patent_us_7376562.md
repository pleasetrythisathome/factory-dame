## Why this matters for factory-dame

This is the **foundational** GrFNN patent. All disclosed material is
public domain since November 2024. It covers:

- Internal coupling matrix `D` between oscillators with integer-ratio
  resonances (1:1, 2:1, 1:2, 3:1, 1:3) — the architecture in our
  Phase 1.1 implementation.
- Per-oscillator time scale `τₙ = 1/fₙ` — Phase 1.2.
- Phantom-fundamental generation through nonlinear cross-coupling.
- The basic GrFNN structure.
- Local-kernel coupling (only oscillators within nearby frequencies
  connect).

We can implement these freely.

## Canonical equation (claim 1, simplified)

```
τₙ żₙ = zₙ(αₙ + bₙ|zₙ|²) + F(z, D) + G(x(t), z, S) + √Q ξₙ(t)
```

- `zₙ` — complex state of oscillator n
- `τₙ` — time constant. Defines natural frequency `f = γₙ/(2π τₙ)`.
- `αₙ` — bifurcation parameter (controls stable fixed points vs. limit cycles)
- `βₙ` — nonlinearity (controls amplitude saturation)
- `F(z, D)` — internal network coupling via matrix D
- `G(x(t), z, S)` — stimulus coupling from input x(t) via matrix S
- `√Q ξₙ(t)` — Gaussian white noise (symmetry-breaker)

## Internal coupling kernel D

Pre-wired connections at small-integer frequency ratios:

| Ratio (target:source) | Coupling form |
|---|---|
| 1:1 | `z_m` (linear) |
| 2:1 | `z_m²` (target at 2× source) |
| 1:2 | `z_m · z̄_n` (target at 0.5× source, subharmonic) |
| 3:1 | `z_m³` |
| 1:3 | `z_m · z̄_n²` |
| 3:2 | `z_m³ · z̄_n` |
| 2:3 | `z_m² · z̄_n²` |

Generic form: target `n` at `f_n`, source `m` at `f_m`, with ratio
`f_n : f_m = p : q`, the resonant coupling term oscillates at `f_n`
when its form is `z_m^p · z̄_n^(q-1)`.

## Demonstration of phantom fundamental

Patent shows: input two-tone complex (e.g., 600 Hz + 900 Hz) →
network generates "strong component at 300 Hz" via the 1:2 and 1:3
sub-harmonic coupling. **This is the residue-pitch / missing-fundamental
mechanism**, generated by the nonlinear coupling, not a separate
extractor.

## Specific parameter values from spec

| Parameter | Symbol | Value |
|---|---|---|
| Time constant | τₙ | 1/fₙ |
| Bifurcation | αₙ | -0.05 to -1 |
| Subharmonic frequency rotation | γₙ | 2π |
| Nonlinear damping | βₙ | -1 |
| Frequency detuning | δₙ | 0 (basic examples) |
| Connectivity | — | Local kernels (nearby freqs only) |

Network frequency layout: 4 octaves (100-1600 Hz) for pitch examples;
0.5-16 Hz for beat tracking. Density: minimum 12/octave recommended,
36/octave used in examples.

## Stability considerations

- Constraint enforced at each step: `0 ≤ |z| < 1/√ε`
- Gaussian noise term destabilizes unstable fixed points and improves
  flexibility. Without it, oscillators stuck on isolated equilibria
  fail to respond to weak stimuli.

## Notes for our implementation

1. **We're using α = -0.05** which is at the lightly-damped end of
   their suggested range. The patent allows up to α = -1 (heavy damp).
2. **β₁ = -1** matches the patent's basic example. Their later patent
   (US 8,930,292) uses β₁ = -100 / -10 / -1 across three layers.
3. **Per-osc τ scaling** is enabled in our config (`per_oscillator_tau =
   true`). This matches the canonical form.
4. **Internal coupling kernel** — implemented but disabled as no-op at
   our drive levels (linear regime). Different from the patent's
   intended high-amp regime.
5. **Local kernel** — we use `max_octave_distance = 2.5` per the
   patent's "local kernel" guidance.
